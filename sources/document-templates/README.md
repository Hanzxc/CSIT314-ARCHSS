# Document format references

`us13-interior-designer-log-in.docx` is the user-supplied formatting sample retained on 2 November 2026. Its original bytes are preserved. It was first used to create `Sprint_3/US21 - View Current IDPs/US21 View current IDPs.docx`.

Use this sample when the user asks for the same project document format: project label, story title, assumptions, user story table, use case diagram, use case description table, four wireframes, BCE class diagram and responsibilities table, sequence diagram, system tests and unit tests. Preserve its typography, colours, table treatments, footers and portrait/landscape layout. Adapt content to the requested story. Test results, estimates and implementation claims from the sample are examples, not facts about later stories.

This reference is source material, not a standing instruction to implement its US13 requirements. Future user requests determine when to use it.
