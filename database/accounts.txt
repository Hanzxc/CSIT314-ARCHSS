ARCHSS demo database - user names and passwords
============================================================
database/archss.db holds the full demo data (README seed order + the system-test accounts).
Demo data only - passwords are stored as SHA-256 hashes in the database, listed here so the team can log in.
Every password below was checked against the database, and every 'log in at' page was checked with
UserAccount.verifyCredentials (the same check the log in pages use).

Everyone logs in at http://127.0.0.1:5000/login and picks the role in "Log in as".
